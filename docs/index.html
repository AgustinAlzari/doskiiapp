cómo instalar desde código

git clone https://github.com/AgustinAlzari/doskiiapp.git
cd doskiiapp && npm install
npm run dev   # vite + electron en http://localhost:5173
npm run build   # verifica build
npm run dist   # genera dmg/zip en release/

requiere Node.js 20+ y npm 10+. los datos de ejemplo (proyecto ansiedad) están en data/ y se sincronizan con ./sync.sh. ver README y AGENTS.
